# VibeSkills

VibeSkills is a simple web application for tracking my progress while learning different skills.

This project was also created as my first experiment with AI-assisted development and vibe coding.

## Features

- Add skills
- Track skill progress
- Update progress
- Delete skills
- Save data using localStorage

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

Through this project, I practiced:

- HTML structure
- CSS styling
- JavaScript
- DOM manipulation
- Event listeners
- localStorage
- Git and GitHub
- AI-assisted development
